# Hank – Guangzhou China Sourcing Landing Page

Single-file static site (`index.html`, inline CSS, Google Fonts "Inter"). No build step.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server` here and visit http://localhost:8000.

## Deploy (GitHub Pages)
1. Create a repo (e.g. `hanzaiheng-cpu.github.io` or `sourcing-site`) and push `index.html` + `README.md`.
2. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.

## To edit before/after launch
- **Fiverr link** is a placeholder profile URL (`https://www.fiverr.com/zaihenghan`). Swap it for the live gig URL once published (search `fiverr.com` in index.html).
- Packages mirror the Fiverr gig draft; prices are intentionally not shown, so keep Fiverr as the source of truth.
- Remove any service or category you can't personally deliver.
- Content rules: no testimonials, stats, client logos or ages unless real.
